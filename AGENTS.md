# Учебный проект

- Писать на понятном начинающему Java-разработчику уровне: небольшие методы,
  обычные классы, явные действия. Избегать лишних абстракций и сложных шаблонов.
- Использовать прямой JDBC: Connection, PreparedStatement, ResultSet,
  try-with-resources. Не заменять его JdbcTemplate, JPA или Hibernate.
- Сохранять разделение Controller → Service → Repository; консольный клиент
  общается с backend только через HTTP, без зависимости на его Java-классы.
- Перед использованием кода из ветки backend проверять его соответствие
  заданию, текущей схеме БД и логике проекта. Не переносить ветку целиком.
- Делать отдельные осмысленные коммиты для завершённых и проверенных частей работы.
- Проверять изменения подходящими тестами; SQL-тесты выполнять в изолированной
  схеме, не очищать рабочие таблицы ради проверки.
- Не сохранять реальные пароли в репозитории.
